# georref-dxf-perimetrico
Georreferencie automaticamente arquivos DXF a partir de roteiros perimétricos e memoriais descritivos. A Skill identifica o perímetro, correlaciona vértices, aplica translação, rotação e ajuste de escala, preservando layers, blocos, textos, cotas e layouts, gerando um DXF georreferenciado com validação técnica.
